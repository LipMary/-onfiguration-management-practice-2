# Визуализатор графа зависимостей пакетов (Вариант №17)

Консольная утилита (CLI) на языке Python для анализа и построения дерева зависимостей пакетов менеджера **npm** без использования сторонних библиотек.

## Реализованные этапы
* **Этап 1:** Чтение и валидация конфигурационного файла формата TOML.
* **Этап 2:** Получение прямых зависимостей реального пакета через API реестра `registry.npmjs.org` (формат JSON).
* **Этап 3:** Построение полного графа зависимостей методом поиска в глубину (DFS), защита от зацикливания и поддержка тестового режима.

## Структура проекта
* `src/main.py` — точка входа в приложение, парсер TOML и проверка параметров.
* `src/fetcher.py` — загрузка данных из сети и чтение тестового репозитория.
* `src/graph.py` — алгоритм обхода в глубину (DFS) и вывод дерева на экран.
* `tests/config.toml` — конфигурация для анализа реального пакета (`express`).
* `tests/test_config.toml` и `tests/test_repo.txt` — файлы для демонстрации тестового режима и обработки циклов.
* `run.sh` — скрипт быстрого запуска.

## Запуск проекта
Для запуска в тестовом режиме выполните команду:
```bash
python3 src/main.py tests/test_config.toml
```

Пример результата работы:
```text
Граф зависимостей для пакета A (1.0.0):
- B
  - D
- C
  - A [циклическая зависимость]
  - D
```
